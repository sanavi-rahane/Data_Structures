1️⃣ Basic Array Operations (Must know)

Ye almost har fresher ko aana chahiye.

Problems:

Find maximum element in array

Find minimum element in array

Find second largest element

Find second smallest element

Reverse an array

Check if array is sorted

Sum of all elements

Count frequency of each element

Linear search

Remove duplicates from sorted array

Goal: Array traversal strong ho.

2️⃣ Index Based Problems

Ye logic building ke liye important hai.

Left rotate array by 1

Left rotate array by K

Right rotate array by K

Move all zeros to end

Move all negatives to one side

Rearrange array alternatively (+ -)

Union of two arrays

Intersection of two arrays

Important concept:

swapping

two pointers

3️⃣ Two Pointer Pattern

Ye interviews me bahut aata hai.

Problems:

Two Sum (sorted array)

Remove duplicates

Container with most water

Pair with given sum

3 Sum (basic understanding)

Key idea:
Left pointer + Right pointer.

4️⃣ Sliding Window Pattern

Internships me frequently puchte hain.

Problems:

Maximum sum subarray of size K

First negative number in window

Count distinct elements in window

Longest substring without repeating (string but same pattern)

Maximum average subarray

Goal:
Window expand / shrink samajhna.

5️⃣ Prefix Sum Pattern

Ye smart optimization hota hai.

Problems:

Range sum query

Equilibrium index

Subarray sum equals K

Count subarrays with given sum

Concept:
precompute → fast queries.

6️⃣ Kadane's Algorithm

Very famous interview question.

Problems:

Maximum subarray sum

Print subarray with maximum sum

Maximum circular subarray sum

7️⃣ Hashing + Arrays

DSA ka real power yaha se start hota hai.

Problems:

Two Sum (unsorted)

Majority element

Missing number

8️⃣ Sorting Based Problems

Simple but asked in interviews.

Problems:

Kth largest element

Check if two arrays are equal

9️⃣ Subarray Problems (Very Important)
